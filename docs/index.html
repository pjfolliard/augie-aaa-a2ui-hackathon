What is Google ADK (Agent Development Kit)?

Google ADK (google/adk-python) is Google's open-source framework powering Gemini Enterprise agents. In AAA, ADK loads the signed-in user's Persona System Prompt, enforces their Advising Scope (RBAC) (from University-Wide down to Self Only), and binds the A2UI component schema.

What is A2UI (Agent-to-UI)?

A2UI (google/A2UI) is Google's open declarative UI protocol. Instead of returning walls of chat text, the ADK agent streams structured JSON (surfaceUpdate + dataModelUpdate) that renders native, interactive DataTables, KPI Cards, Progress Bars, and Approval Forms.

Built for Blind, Deaf, Low-Vision & International Vikings

Every A2UI component enforces WCAG 2.2 AA/AAA: screen-reader <caption> & scope headers, 14.8:1+ Sioux Falls Navy/Gold contrast, structured status labels, 100% visual parity (zero audio-only cues), plain-language US higher-ed glossary, and F-1 Visa 12-credit guardrails.

📐 Zion Cloud Solutions Spec: A2UI v0.9 in Gemini Enterprise (“What You Can and Can't Do”)

Incorporated directly from Zion Cloud Solutions' Gemini Enterprise A2UI v0.9 engineering briefing (version: "v0.9", official 69-component composite catalog gemini_enterprise_composite_catalog.json, and A2A v0.3 on Cloud Run):

Zion Cloud Solutions — Gemini Enterprise A2UI v0.9 Guardrails & Architecture Checklist
Dimension What You Can Do (Supported in v0.9) What You Can't Do / Must Avoid
Protocol & Catalog Use "version": "v0.9" on every message and declare https://www.gstatic.com/vertexaisearch/a2ui/v0_9/gemini_enterprise_composite_catalog.json (69 components across Basic, Material, and Canvas). Do not use A2UI v0.9.1 or invent custom component types outside the composite catalog.
Hosting & A2A Version Host as an A2A v0.3 agent on Google Cloud Run (grant roles/run.invoker to Discovery Engine service agent on .run.app, or OAuth behind custom domain/LB/Apigee). Cannot host an A2UI agent on Vertex AI Agent Engine, and cannot use API keys or custom HTTP headers.
Security & Form Actions Call Google Cloud Model Armor directly inside the agent and re-validate all incoming action form payloads server-side. Gemini Enterprise's built-in Model Armor does not cover A2A agents automatically; client form payloads can be tampered with.
File Exports & Rich Media Send downloadable files (PDF degree audits, SAP CSV exports) as A2A file parts; use Image/MaterialImage and MaterialButton with openUrl. Files saved with ADK's save_artifact do not reach Gemini Enterprise; markdown links/images inside Text do not render.
