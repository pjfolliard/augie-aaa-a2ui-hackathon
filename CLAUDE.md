# CLAUDE.md — Claude Code Instructions for Augustana University AAA A2UI Hackathon

Please read and follow all rules in [`AGENTS.md`](./AGENTS.md) and [`GEMINI.md`](./GEMINI.md).

## Quick Commands
* **Rebuild JSON & JS data bundles from CSV:** `python3 scripts/build_data.py`
* **Sync from Google Sheets via `gws` / `gsheets`:** `./scripts/gws_sync_personas.sh`
* **Run Accessibility & Schema Verification:** `python3 scripts/validate_project.py`
* **Preview Workbench Locally:** Open `docs/index.html` in a browser or run `python3 -m http.server 8080 --directory docs`
